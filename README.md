> **Stop writing 50+ variations manually and guessing character limits.**

Paid media teams waste hours writing ad variations by hand, only to have them rejected by the platform for exceeding character limits. This agent generates 3 structured hooks (fear, gain, logic) mapped to your buyer persona, then **runs a Python script to validate every character limit** before outputting a ready-to-upload matrix.

### ✨ Enterprise Features
* **Triple-Hook Framework:** Synthesizes Fear, Gain, and Logic-based copy for every variant.
* **Deterministic Validation:** `validate_length.py` enforces platform limits (X, Meta, LinkedIn) with zero guessing.
* **Variant Matrix:** One clean table, upload-ready, with a proof log of passed validations.
* **Persona Locked:** All copy is anchored to the audience profile you define upfront.
